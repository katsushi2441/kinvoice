# kinvoice — 領収書をPDFで発行して、メールで送る

**領収書をPDFで発行し、ダウンロードURLをお客様へメールで送る**システムです。

- **データベース不要。** PHPが動くサーバーがあれば動きます
- **外部ライブラリ不要。** Composer も npm も使いません
- 約1,180行。全部読めるサイズです

デモ: <https://proto.exbridge.jp/kinvoice/>（パスワード `demo2026`・メールは送信されません）

## 仕組み

```
管理者が発行  →  メールでURLを送る（PDFは添付しない）
                      ↓
              お客様がURLを開く
                      ↓
              メールアドレスを入力
                      ↓
              一致したらPDFがダウンロードされる
```

**PDFをメールに添付しません。** 宛先を1文字間違えた瞬間に、領収書が他人の手元に残るためです。
推測困難なURL（32桁）と宛先メールアドレスの2つが揃わないと開きません。

認証前の画面には、顧客名も金額も領収書番号も出しません。URLだけが漏れたときに
「誰宛のいくらの領収書か」が分かってしまうためです。
メールアドレスを10回間違えるとロックし、管理画面から解除します。

## 設置

1. `public/` の中身をサーバーに置く（FTPで上げるだけ）
2. 管理パスワードのハッシュを作る

   ```bash
   php scripts/make_password_hash.php 'あなたのパスワード'
   ```

3. `kinvoice_config.php.example` をコピーして `kinvoice_config.php` を作り、値を入れる

   ```php
   define('KINV_ADMIN_PASSWORD_HASH', '手順2で出た文字列');
   define('KINV_NAME', '発行元の会社名');
   define('KINV_MAIL_FROM', 'メールの送信元アドレス');
   ```

4. `kinvoice.php` を開いてログイン

設定が足りないうちは、管理画面が**不足している項目を名指しで表示**します。
設定を置くまで誰もログインできません。`kinvoice_data/` は自動で作られます（書き込み権限が必要）。

### メールが届かないとき

まず **SPF** を疑ってください。共有サーバーから送る場合、送信ドメインのSPFに
そのサーバーが含まれていないと、受信側で捨てられます。
**`mail()` は成功を返すので、送信履歴上は「送信済」に見えます。**

```bash
dig +short TXT example.co.jp | grep spf
```

`KINV_MAIL_FROM` を、そのサーバーから送れるドメインのアドレスに変えてください。

### 設定を公開領域の外に置く

`KINV_CONFIG_FILE` を先に定義すれば、設定ファイルの場所を変えられます。

```php
define('KINV_CONFIG_FILE', dirname(__DIR__) . '/kinvoice_config.php');
```

### ログイン方式

既定は**パスワード**です。X(Twitter)のOAuth基盤を別に持っている場合は
`KINV_AUTH` を `'x'` にすると、`auth_common.php` を使う方式に切り替わります。

## 領収書としての体裁

宛名・金額（税込）・但し書き・発行日・発行元・税率ごとの内訳。
**電子交付のため収入印紙は不要**である旨も印字します。

適格請求書発行事業者の登録番号は、設定したときだけ印字します。
**未取得のまま架空の番号を入れないでください**（未設定なら「記載しておりません」と出ます）。

税額の内訳は、端数が出ても**合計が必ず税込総額に一致**します
（9,999円 → 9,090 ＋ 909）。ここが1円ズレると領収書として使えません。

## 構成

| ファイル | 役割 |
|---|---|
| `public/kinvoice.php` | 管理画面（発行フォーム＋送信履歴一覧） |
| `public/kinvoice_dl.php` | お客様用ダウンロードページ |
| `public/kinvoice_auth.php` | 管理者ログイン |
| `public/kinvoice_lib.php` | 台帳・税計算・メール送信 |
| `public/kinvoice_pdf.php` | 領収書PDF生成（外部ライブラリ非依存） |

台帳は `public/kinvoice_data/receipts.json` に flock 付き。`.htaccess` で直接アクセスを塞ぎます。

```bash
php scripts/check_kinvoice.php   # 台帳・認証・税計算・PDF の確認（46項目）
php scripts/check_demo.php       # デモモードの確認（メールを送らないこと）
```
